# 卡司：放进你自己的 IP 和宠物

<p align="center"><img src="../docs/images/cast.png" alt="两个角色位，四条路" width="360"></p>

每支 Scale Map 片子里有两个固定角色位：

- **叙事 NPC**：你的 IP。一个属于历史现场的人，站在 1901 年的围观人群里，或者 1950 年工厂的楼梯上，同时也是画面的比例尺。他不当主持人，不对着镜头讲解，观众的感觉是「他好像一直都在那儿」。
- **彩蛋**：你的宠物或吉祥物。每种画风最多藏一次，负责一点荒诞，让人回头再找一遍。它不讲道理，也不和 NPC 绑在一起出场。

系列默认的卡司是 David ＋ 小龙虾（[david/](david/)）。换成你自己的猫、狗、品牌吉祥物或者你本人，不用改任何规则，建一套自己的卡司，在产品的 `product.yaml` 里写 `cast: <你的 id>` 就行。

做法借鉴 [huashu-art-motion](https://github.com/alchaincyf/huashu-art-motion) 的角色规范（它的 `references/10-角色.md` 和 `references/角色精细度.md`），核心是一句话：**角色要么画到位，要么不出脸。** 粗糙的角色比没有角色更差，观众看见一个圆头豆豆眼的小人，第一反应就是「AI 做的」。

## 三条路，只有三条

每个角色位选一条路，写在 `cast.yaml` 的 `route` 里：

| route | 什么时候走 | 怎么做 |
|---|---|---|
| `frames` 帧库 | 你有定稿的形象，并且有生图工具（或者已经有画好的动作帧） | 用参考图让 AI 按片子的画风生成动作帧，绿幕抠图，切成帧库，代码只管位置、大小、朝向和换帧。要过下面的交付线 |
| `back-only` 只出手和背影 | 还没有帧库，但故事需要这个人 | 背影、剪影、过肩、一双手；脸不出画。靠帽子、发型、包、站姿这些剪影特征让人认出来 |
| `code` 代码画（只给彩蛋） | 小动物或小物件，本来就是个剪影 | 在 `motion/kit` 里写一个画剪影的函数，不画眼睛和脸，每种画风一个版本 |
| `none` | 这一套不设这个角色 | 片子里就不出现 |

代码不画人脸，也不给物加脸。这条是 huashu 的硬规矩，Scale Map 照搬：代码画出来的 Q 版小人、白壳机器人、带笑脸的物件，一眼就是 AI 味。

## 建一套自己的卡司

```sh
tools/cast.sh new mimi 阿明 --egg 咪咪
```

参数依次是卡司 id（小写英文、数字、连字符）、NPC 的名字，`--egg` 是彩蛋的名字。默认建在你自己的配置目录 `~/.config/scale-map/cast/mimi/`，**不进仓库**：你的照片和形象不会随仓库公开。想把它作为公开卡司放进仓库，加 `--public`，会建在 `cast/mimi/`。

建好后的目录：

```
mimi/
├── cast.yaml       定规：名字、走哪条路、身份特征
├── refs/           参考图：正面照、三视图设定稿（只放你有权使用的）
└── frames/         帧库：一个动作一个文件夹
    ├── walk/       01.png … 08.png ＋ meta.json
    └── point/
```

然后在产品的 `product.yaml` 里写：

```yaml
cast: mimi
```

`motion/sync.sh` 渲染时按这个顺序找卡司：产品子仓库里的 `cast/<id>/` → 你的配置目录 `~/.config/scale-map/cast/<id>/`（可用环境变量 `SCALE_MAP_CAST_HOME` 改）→ 本仓库的 `cast/<id>/`。找到后把帧库带进引擎，场景代码里用 `SM.npc(...)` 和 `SM.egg(...)` 放角色。

检查一套卡司写全了没有：

```sh
tools/cast.sh list          # 能找到的所有卡司，标出在哪
tools/cast.sh check mimi    # 定规有没有写、帧库格式对不对
```

## 写定规

`identity` 是每次生图都要写死的身份特征。只写看得见、能核对的东西，模型爱自作主张的地方尤其要写清：

```yaml
identity:
  - 纯白渔夫帽（不是浅灰，要写死）
  - 圆框黑眼镜
  - 白 T、卡其短裤、白洞洞鞋
  - 左手腕黑手表
  - 大头小身体
```

这一组是 huashu 作者花叔的定规，照这个粒度写你自己的。宠物也一样：毛色和花纹在哪、耳朵是立的还是折的、尾巴多长、项圈什么颜色。

`silhouette` 是只出背影时也能认出来的特征：帽子轮廓、发型、背包、站姿。走 `back-only` 的角色，靠这几条在人群里被找到。

## 做帧库（route: frames）

1. **参考图**：正面照或三视图设定稿放进 `refs/`。
2. **按画风生成**：用支持参考图的生图模型。提示词写清三件事：
   - 这支片子画风的**造型语法**，不只写「扁平风格」。比如「纯色块不描边，阴影用同色相深一档」；
   - 身份定规，逐条写进去；
   - 姿势和镜头调度，比如「侧身朝右，伸手指向右边」。
   要动的话，一张图出多帧：4×2 八帧，写明「同一角色」「每帧站在格子底部居中、大小一致」。背景用绿幕 `#00B140`（白衣服别用白底）。
3. **抠图切帧**：用 huashu 的 `scripts/key_split.py` 抠绿幕、按列切成单帧，存成 `frames/<动作>/01.png … 08.png`。
4. **写 meta.json**：每帧的脚底锚点和尺寸，格式和 huashu 长卷示范的帧库一样：

```json
{
  "frames": [{ "file": "01.png", "ax": 134, "ay": 387, "w": 246, "h": 388 }],
  "ref_h": 396
}
```

`ax, ay` 是脚底中心在这张 PNG 里的像素位置，`ref_h` 是站直时的身高像素。引擎按 `floor(t × 9) % 帧数` 换帧，不做补间。

## 交付线：帧库角色要过这八条

照搬 huashu 的标准。截一张角色特写放大到 2 倍，逐条打勾，写进交付说明；过不了就回去重新生成，或者改走 `back-only`。

1. **剪影认得出**：涂成纯黑，还认得出是谁、在做什么。
2. **比例有骨架**：有脖子、肩、肘、腕；头身比全片不变。
3. **手是手**：看得出手指，能真的握住物。
4. **至少两层明暗**：底色＋阴影，再加高光或边缘光，光的方向和场景一致。
5. **至少三处材质细节**：衣褶、缝线、发丝、布纹、表带……
6. **表演是具体的**：每次出场的表情和姿势都对得上这一镜在讲的事。
7. **和画风同一套**：线条、上色、色板和背景同一种画法，不是一张贴纸。
8. **前后一致**：每一镜的五官、发型、衣服、配色都一样。

## 版权和边界

- 只放你本人、你的宠物，或你有权使用的形象。别人的 IP、品牌吉祥物、公众人物的脸，不放进卡司。
- 公开卡司（`--public`）会随仓库一起被别人看到和拉走。私人形象建在配置目录里，默认不公开。
- `cast.yaml` 的 `rights` 写清这套形象能用在哪里。David 和小龙虾只用于本系列，不随仓库授权给其他用途。
- 角色涉及未成年人时，服装一律端庄。
