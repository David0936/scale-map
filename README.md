# Scale Map

**把产品放回人类文明尺度中观察。**

Scale Map 是一套研究驱动的视觉叙事系统。它从人的欲望出发，沿着时间、人物、空间与物的形态追踪一个产品为何出现、为何长成今天这样，并在最后追问：当需求被彻底解决，产品本身是否还需要存在？

它不是科技产品介绍模板，也不是“找几幅名画来恶搞”的提示词合集。

> **Never decorate history. Visualize it.**  
> 不要拿历史做装饰，要让视觉本身承担叙事。

## 六层地图

- **HUMAN｜人的欲望** — 人为什么需要它？
- **TIME｜时间** — 从原始行为经过哪些节点走到今天？
- **PEOPLE｜人物** — 谁真正改变了路径？
- **SPACE｜空间** — 它怎样进入家庭、建筑、城市和生活？
- **OBJECT｜物** — 它为什么最终形成今天的形态？
- **FUTURE｜未来** — 当同一个需求被彻底解决，这个产品还会存在吗？

默认成品为 5–8 张视觉叙事，推荐 6 张：HOOK、BEFORE、TURNING POINT、EVOLUTION、NOW、AFTER。每张只承担一个观点。

## 两个角色

**David 是 Narrative NPC。** 他不站在每页中心讲解，而是属于历史现场的人，也是建立空间尺度的 scale figure。默认六张中封面出现一次，正文随机出现一至两次；正文不看镜头。

**小龙虾是 Visual Easter Egg。** 它负责一点荒诞和寻找乐趣，不必与 David 绑定，也不承担知识解释。

## 使用

将本仓库作为 Codex Skill 使用后，可以直接提出：

> Scale Map：蒸馏洗衣机。

Skill 会产出研究论点、六层地图、逐页故事板、视觉与角色调度、可生成的图像 brief、发布文案和证据账本。
